## 🧠 Models Used

Three classification models were trained and evaluated:

### 1. Logistic Regression

A classification algorithm used as one of the baseline models.

### 2. Decision Tree

A tree-based classification algorithm that makes decisions using feature-based splits.

### 3. Random Forest

An ensemble classification model consisting of multiple decision trees.

---

# 📈 Evaluation Metrics

The models were compared using:

| Metric | Purpose |
|---|---|
| Accuracy | Measures overall correct predictions |
| Precision | Measures correctness of positive predictions |
| Recall | Measures how many positive cases were identified |
| F1 Score | Combines Precision and Recall |

---

# ⚙️ Model Tuning

The **Random Forest** model was optimized using:

```text
GridSearchCV
```

The tuning process searches different combinations of:

```text
n_estimators
max_depth
min_samples_split
```

The best-performing configuration is selected using cross-validation.

### Tuning Workflow

```text
Random Forest
      ↓
Parameter Grid
      ↓
GridSearchCV
      ↓
Cross-Validation
      ↓
Best Parameters
      ↓
Optimized Model
      ↓
Test Evaluation
```
